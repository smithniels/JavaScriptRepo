Increment and Decrement counter

Explanation

  • In this code, we have a simple counter that can be incremented, decremented, and reset. The counter value is displayed in the h2 element with the id counting.
  • Theincrement(), decrement(), and reset() functions are called when the respective buttons are clicked.
  • These functions update the counter value and display it in the h2 element.
  • When each button is pressed 3 things can happen:
    1. The increment button will add 1 to data
    2. Tbe decrement button will subtract 1 from data
    3. The reset button will set data to 0
